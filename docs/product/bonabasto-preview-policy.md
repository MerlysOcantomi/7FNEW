# Bonabasto preview publication policy

This document is the permanent preview publication contract for Bonabasto.

## Canonical preview

Bonabasto owner-facing review always uses:

```text
https://preview-bonabasto.sevenef.com
```

The Vercel project is:

```text
7-fnew
```

The Vercel environment is:

```text
Preview
```

The permanent Git branch assigned to that domain is:

```text
preview-bonabasto
```

## Permanent rule

The canonical Bonabasto domain MUST NOT be bound to temporary implementation branches such as:

```text
work/7f-bonabasto-00
work/7f-bonabasto-01
work/7f-bonabasto-02
```

Temporary session branches may be used for implementation when justified, but owner-facing review is always promoted to:

```text
preview-bonabasto
```

Therefore the maintainer should not need to change the Vercel domain-to-branch mapping between Bonabasto sessions.

## Publication flow

```text
implementation branch
        |
        v
validate
        |
        v
preview-bonabasto
        |
        v
https://preview-bonabasto.sevenef.com
        |
        v
owner review
        |
        v
master when approved and safe
```

If work is performed directly on master, the reviewable Bonabasto state is still promoted to
`preview-bonabasto` before asking the owner to review the canonical Bonabasto preview.

## Separation from the v0 prototype

The Vercel project/repository named `bonabasto` remains a product/UX prototype reference.

The canonical Bonabasto preview MUST point to the Bonabasto implementation inside `7FNEW` / Vercel project
`7-fnew`, never to the standalone v0 prototype.

## Operational responsibility

Whenever Bonabasto work is ready for visual review:

1. verify the intended Bonabasto implementation;
2. promote that reviewed commit/state to `preview-bonabasto`;
3. verify the Vercel Preview deployment is READY;
4. verify `https://preview-bonabasto.sevenef.com` resolves to that preview;
5. give the owner the canonical domain, not an autogenerated `*.vercel.app` deployment URL.

The domain-to-branch mapping is configured once and remains stable.
